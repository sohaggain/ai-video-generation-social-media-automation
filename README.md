# 🎥 AI Video Generation & Social Media Automation System

An end-to-end AI-powered content automation system built with **n8n** that automatically generates ideas, scripts, captions, prompts, AI videos, and publishes content across multiple social media platforms.

The workflow combines AI, automation, and social media integrations to eliminate repetitive content creation while enabling consistent and scalable digital marketing.

---

# 🚀 Features

- AI-powered content generation
- Automatic video idea generation
- AI script writing
- AI caption generation
- Prompt generation for AI video models
- AI video creation with Veo 3
- Automatic video retrieval
- Multi-platform social media publishing
- Workflow automation with n8n
- AI-powered content marketing

# ⚙ Workflow Overview

1. Generate content ideas using AI.
2. Create engaging video scripts.
3. Generate captions and hashtags.
4. Create prompts for AI video generation.
5. Generate videos using Veo 3.
6. Retrieve the completed video.
7. Prepare platform-specific content.
8. Publish automatically across multiple social media platforms.
9. Log content status and metadata in Google Sheets.
